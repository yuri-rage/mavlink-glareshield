# Examples

Files to import into Glareshield, to use as they are or as a starting point.

| File | What it is | How to import |
| :--- | :--- | :--- |
| `zero-turn-mower.widget.json` | One custom widget: GPS, engine RPM and both drive throttles for a zero-turn mower | Edit Mode → **Add Widget** → **Upload .json Widget** |

A whole dashboard (a profile) is imported in Edit Mode → **Profiles & Backup** → Import Profile, which replaces your
whole dashboard: export yours first. The default dashboard is described in the
[user guide](../docs/user-guide.md#the-default-dashboard); **Reset to Default Layout** (Profiles & Backup) brings it
back.
